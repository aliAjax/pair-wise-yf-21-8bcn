# hxyfront-62009 地毯修复取送暂存台

在原有地毯修复档案页基础上改造的取送暂存台。

## 业务规则

- 到店登记：送修人、承诺取件日、暂存位、修复工序，列表支持按产地筛选。
- 整单拒绝（列表、暂存位、工序进度均不变）：
  - 同毯重复送修（在店单中毯号重复）；
  - 承诺取件日早于入店日；
  - 暂存位已被在店单占用；
  - 未登记任何修复工序。
- 取件后释放暂存位，单据转为只读归档记录。
- 承诺取件日早于当天自动标记逾期（每日刷新）。
- 改期须填写原因，旧/新日期、原因与时间写入改期历史，只追加不改写。
- 数据保存在浏览器 localStorage，重开页面仍在。

## 代码结构

业务拆分为三个文件：

- `src/staging/rules.ts` — 类型、常量与纯函数校验规则（登记/改期/逾期/暂存位占用）；
- `src/staging/store.ts` — 状态管理与 localStorage 持久化；
- `src/staging/StagingPage.tsx` — 页面（登记表、产地筛选、暂存位看板、进度、改期、取件归档）。
