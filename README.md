# hxyfront-62009 地毯取送暂存台

由手工地毯修复工作室的纹样档案页改造而来，现用于到店送修地毯的取送暂存管理：登记送修人、承诺取件日、暂存位与修复工序，按产地筛查看管在店地毯。

## 业务规则

新增到店须同时通过以下校验，任一不通过则**整单拒绝**（列表、暂存位、工序进度均不变）：

1. **同毯重复送修**：同一毯号尚有未取件工单时不可再次登记（毯号大小写归一）；
2. **取件日早于入店日**：承诺取件日不得早于入店日；
3. **暂存位被占用**：在店工单占用的暂存位不可再选；
4. **工序未完成**：至少登记一道修复工序。

其余规则：

- **取件**：办理取件后释放暂存位，工单转为只读档案，不可再改期或更新工序；
- **逾期**：打开页面时按当前日期自动推导，超过承诺取件日仍在店即标「逾期」；
- **改期**：必须填写改期原因，每次改期追加历史记录（原日期、新日期、原因、时间），不覆盖；
- **持久化**：数据保存在浏览器 `localStorage`（键名 `carpet-staging-desk:v1`），关闭重开仍在；侧栏可一键恢复演示数据。

## 代码结构（规则 / 状态 / 页面三分离）

- `src/business/rules.ts` — 类型、常量（产地、暂存位、预设工序）、到店校验、状态推导、进度与改期校验等纯规则；
- `src/business/state.ts` — localStorage 持久化、订阅通知、到店 / 取件 / 改期 / 工序切换等状态操作；
- `src/business/StagingDesk.tsx` — 暂存台页面：登记表单、拒单提示、产地筛选、暂存位看板、工单卡片、改期历史、只读取件档案。
